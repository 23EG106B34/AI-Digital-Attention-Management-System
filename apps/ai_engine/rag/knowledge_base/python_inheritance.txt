Python inheritance allows a child class to reuse and extend the
behaviour of a parent class. A child class declared as
"class Child(Parent):" inherits attributes and methods from Parent.
The child can override methods, call the parent implementation with
super(), and add new attributes. Multiple inheritance and the method
resolution order (MRO) determine lookup order. Inheritance supports
code reuse and polymorphism: objects of different subclasses can be
treated through a common parent interface.
